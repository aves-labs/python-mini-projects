# Python Mini Projects 🐍

A collection of utility scripts, algorithmic puzzles, text-based interactive tools, and automation practice scripts built in Python.

## Included Scripts & Utilities

- **`Build_pyramid_01.py`**: Generates a symmetric, centered text-based star pyramid based on a user-provided integer height.
- **`check_ipv4.py`**: Validates a string format IPv4 address, ensuring proper octet ranges (0–255) and blocking invalid leading zeros.
- **`Goldbach's conjecture problem 01.py`**: Evaluates even integers up to 3000 to find and list all prime number pairs that sum to the target number.
- **`HashGenerator_01.py`**: Transforms phrase inputs into capitalized hashtag strings, enforcing character limits (max 140 characters).
- **`infinity_print.py`**: Interactive typewriter-effect text printer that loops custom messages at specified intervals.
- **`multiplicationQuiz.py`**: A timed, interactive 10-question multiplication quiz using `pyinputplus` with custom score tracking and accuracy calculation.
- **`pyMode.py`**: A quick clipboard helper script that formats and copies study prompts for *Automate the Boring Stuff with Python*.
- **`random_Binary.py` & `Test1.py`**: Stream generators that output random binary digits (`0` or `1`) with custom delays and loop counters.
- **`Rot13.py`**: An interactive ROT13 substitution cipher encoder and decoder supporting both uppercase and lowercase letters.
- **`Sandwich_maker.py`**: An interactive terminal ordering system that calculates itemized costs for custom breads, proteins, cheeses, and optional toppings using `tabulate` and `pyinputplus`.
- **`StripComments.py`**: Parses strings and strips out comment blocks based on custom marker characters while preserving line structures.
- **`TraningOnCountDown.py`**: An anagram/word-puzzle solver that finds the longest valid matching words from a pool of given letters.
- **`pyMode.py`**: Quick clipboard template generator for study sessions.
